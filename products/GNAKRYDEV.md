## Overview

**GNAKRYDEV** is the technology studio of the GNAKRY ecosystem, focused on designing and building production-ready digital products for African businesses.

The studio covers web platforms, mobile applications, SaaS products, MVP development, API integration and ongoing technical maintenance.

The production repository is **private**. This page is a public product brief and intentionally exposes no proprietary code, credentials or infrastructure details.

---

## Current platform

The current GNAKRYDEV platform includes:

- Conversion-focused responsive website
- Detailed service pages
- Project and portfolio presentation
- Quote-request workflow
- Secure administrative back office
- PostgreSQL/Supabase persistence
- Private attachment storage
- Transactional email notifications
- Bilingual FR/EN editorial capabilities
- SEO, sitemap and Open Graph metadata
- Commercial conversion analytics

---

## Technology direction

The current platform is built around a modern TypeScript web stack with **Next.js, Supabase/PostgreSQL, server-side validation and secure administration**.

The implementation repository remains private because it contains the operational product architecture and commercial workflows.

---

## Role in GNAKRYGROUP

GNAKRYDEV is the engineering and delivery layer of the ecosystem: it builds products for clients while also strengthening the technical capabilities used across GNAKRY products.
