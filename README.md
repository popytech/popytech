## 🧭 Mon approche

`Problem-first` → `Product-driven` → `Build` → `Ship` → `Learn` → `Scale`

- Comprendre le problème opérationnel avant la technologie.
- Relier expérience utilisateur, logique métier et engineering.
- Livrer des versions utilisables rapidement puis itérer.
- Garder privé ce qui relève du code propriétaire, des intégrations et de l'architecture de production.
- Construire depuis la Guinée avec une ambition africaine.
